# Fishing Game Source Code | Fishing Coin Lobby Platform


[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md)


Fishing Coin Lobby is a commercial arcade fishing game source-code project for product evaluation, private deployment, and secondary development. It covers classic fishing gameplay, boss events, tournament modes, jade-room gameplay, activity systems, rankings, safe, shop, tasks, jackpot, scratch-card and wheel events. The project is suitable for iOS, Android and multi-language product customization.

## Read and Download

- Read this README first to understand gameplay, modules, architecture, deployment and customization scope.
- Product screenshots are loaded from the real repository path `docs/assets/screenshots/`. Keep the folder and file-name casing exactly the same when uploading.
- For source-code evaluation, demo builds, deployment or secondary development, contact the project owner by Email or Telegram.

## Main Features

- Classic fishing, boss attack, tournament, jade-room and exciting arcade modes.
- Shop, profile center, treasure box, leaderboard, safe, friends, mail, settings and operation modules.
- Tasks, daily login, activity center, invitations, Jackpot, scratch-card, wheel and rewarded ads.
- Multi-language support for Chinese, English and other localization needs.
- Client, server, operation backend and database components for fast customization.
